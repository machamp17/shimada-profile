# 島田 栄顕 ｜ ファイナンシャルプランナー自己紹介LP

独立系ファイナンシャルプランナー／キリスト教会伝道師・島田栄顕の自己紹介ランディングページです。

## 公開方法（GitHub Pages）

1. このリポジトリの中身を、新規リポジトリ（例: `eiken-profile`）のルートにアップロード
2. **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、Branch を `main` ／ フォルダを `/ (root)` にして Save
4. 数分後に発行される `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

ルートの `index.html` がそのままトップページとして表示されます。

## ファイル構成

```
index.html        … ページ本体（トップページ）
support.js        … 描画ランタイム（index.html と同じ階層に必須）
image-slot.js     … 画像表示用スクリプト（同上）
assets/
  hero-bg.png     … トップの背景＋人物写真
  eiken-photo.png … 人物写真（予備）
  mission.webp    … Mission セクションの写真
  note.webp       … note バナー画像
```

> `index.html` `support.js` `image-slot.js` `assets/` は同じ階層関係のまま配置してください（パスが相対指定のため）。
> 日本語フォントは Google Fonts から読み込むため、初回表示時にネット接続が必要です。
